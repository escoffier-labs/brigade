- The Claude Stop gate requires a passing receipt for the command declared in `verify/required-check.json` or a completed manifest run. If the Git base is unresolved, Brigade trusts local `HEAD` first and then the working tree if `HEAD` has no declaration or is unavailable. Stop reports the fallback source and stays audit-only when neither copy exists. Invalid declarations block with the file path and parse error.
- Stop checks a receipt against the current policy, and verify reruns commands when the policy identity changes. Stop suggests a POSIX shell command using `--argv-json` and explains why a recent ineligible run did not count. If policy lookup exhausts its time budget, Stop skips the check and reports the timeout.
