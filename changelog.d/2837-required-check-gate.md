- The Claude Stop gate requires a passing receipt for the command declared in `verify/required-check.json` or a completed manifest run. If the Git base is unresolved, Brigade checks the fetched default-branch tip, local `HEAD`, then the working tree. The gate stays audit-only when no copy exists. Invalid declarations, including command prefixes with backticks or control characters, block with the file path and parse error.
- Stop checks a receipt against the current policy, and verify reruns commands when the policy identity changes. Stop suggests a POSIX shell command using `--argv-json` and explains why a recent ineligible run did not count. If policy lookup exhausts its time budget, Stop skips the check. Stop includes policy fallback and timeout details in blocking responses.
