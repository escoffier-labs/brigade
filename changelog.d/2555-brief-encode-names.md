- `brigade work brief` sends every value it prints that came from the filesystem, from Git, from configuration or from ingested content through the encoder the instruction-budget lines use: only ASCII letters, digits and `. _ - / ~` pass, every other character is written as an escape, the length is capped with a visible `[truncated]` mark, and the line keeps its fixed prefix. A plain path or identifier still prints unchanged.
- Covered surfaces: dirty and untracked `git status` entries (the status code is git's own and prints as is), the branch, session paths, titles, notes and handoff paths, dogfood run fields and next-task text, task and import text with their ids, sources and kinds, hub overlap rows, cloud stale rows, scanner, sweep, review, care, backup, daily, phase, tool, roadmap, repo-fleet, context, project, learning, research, operator, handoff and recent-session rows, the suggested command's task argument, and the `fleet_routing` block and outcome-ratchet line.
- Values Brigade composes itself (counts, fixed statuses, health detail sentences, and commands with no untrusted argument) stay readable, and so does the default review text the brief writes itself.
