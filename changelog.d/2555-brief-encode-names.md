- `brigade work brief` escapes every value it prints that came from the filesystem, from Git, from configuration or from ingested content, but only where it has to: letters, digits, spaces and printable punctuation stay readable, and a line break, a NEL, a line or paragraph separator, another C0 or C1 control, an ANSI escape, a bidi control, a zero-width or invisible format character and a backslash become an escape such as `\x0a` or `\u2028`. A long value ends in `[truncated]`. A plain path or sentence renders as written.
- Every printed line of the text brief also passes one sanitizer on its way into a buffer, and the buffer is written once, so `sys.stdout` is never swapped. No value can start a new line or hide text even at a site nobody escaped, and two briefs can render at once.
- Covered surfaces: dirty and untracked `git status` entries (the status code is git's own and prints as is), the branch, session paths, titles, notes and handoff paths, dogfood run fields and next-task text, task and import text with their ids, sources and kinds, hub overlap rows, cloud stale rows, health row details, section exception details, scanner, sweep, review, care, backup, daily, phase, tool, roadmap, repo-fleet, context, project, learning, research, operator, handoff and recent-session rows, the pantry role, peer and last sync, the notifications status, the `fleet_routing` block and the outcome-ratchet line.
- A suggested command quotes each task text for the platform's own shell, so `brigade work run 'review the auth module'` on a POSIX host and `brigade work run "review the auth module"` on Windows both print a runnable command, and a Windows path with no space prints unchanged. The command is printed as `withheld (unsafe characters; see --json)` only when the text holds a dangerous character. A command read from a record is withheld when it holds a shell metacharacter, a Windows expansion or a control character. The JSON payload still carries the real command.
- The `work_mode_pin` line keeps its fixed prefix readable and escapes only the exception after it. The suppression command quotes the paths it embeds, so a repository path with a space still gives a runnable command.
