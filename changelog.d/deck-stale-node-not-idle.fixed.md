- The Hub overview deck no longer shows a node whose native T3 observer stopped reporting as idle. The routing snapshot now classifies each machine with the same T3 health check placement uses, so a stale, failed, missing or unreadable observer reports unknown free slots (`sessions-unknown` or `t3-health-missing`) instead of the slots left by expired session rows. The deck renders that machine as unknown, adds nothing to the Idle or Offline cards (the Idle card says how many it could not count), keeps the verdict at COVERAGE UNKNOWN instead of ALL CLEAR, and names the reason in the control-plane table. Fresh nodes render as before.
