- The status file is written only into an existing compose-owned 0700 memory directory, as the compose owner with mode 0600 via a temp file and rename; a root-owned or unwritable directory only warns and never changes the backup outcome (#2296).
- A wedged `docker exec` now fails one row with a reason instead of aborting the check with a traceback, and the memory probe stays PENDING with a clear reason when the hub is stopped rather than starting the one-shot backup service (#2296).
