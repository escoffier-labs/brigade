Each row carries a new `attribution_source` (`session_observed`; explicit ids are `caller_typed`, and older rows read as `caller_typed`). The literal `auto` is never written. When no skill resolves (a Codex repo, a plain shell) the run falls back to `brigade-work` as a `caller_typed` capture and prints one note, so the loop never records nothing.
