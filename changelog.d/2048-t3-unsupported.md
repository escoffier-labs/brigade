- `brigade t3 open` classifies every task against a closed structural-gap table before writing anything, and refuses the whole batch with `t3-unsupported` when a target driver, locality or mode is one T3 cannot run. Only the affected caller-chosen task ids and their tokens reach stderr, and no run directory, asset or journal fact is created.
- `brigade t3 claim` reports the same structural token instead of `admission-denied` when a retained target or an edited declaration is structurally unrunnable, while every policy, capacity, authority, seat and adapter refusal keeps its own code.
- Document that tasks refused as `t3-unsupported` go to a separate `brigade run batch` request with its own admission, budget and receipts, that no reroute verb or budget transfer exists inside a governed run, and that `asset-digest` is a readback refusal rather than an open refusal.
