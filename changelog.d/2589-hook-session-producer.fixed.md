- `brigade work start` no longer loses the first column of `git status --short`, so a subject that was the first dirty line at session start (an unstaged modification) now reads as already dirty instead of clean. The dirty-subject check also unquotes git's quoted paths (spaces, non-ASCII), reads a renamed file's old and new paths, and treats a collapsed untracked directory line such as `?? newdir/` as dirty for every subject under it (#2589).
