- Hub memory scan bundle `brigade-memory-scan.v7` normalizes the scan copy with NFKC instead of the full-width ASCII fold, in the Python scanner and in the native hub (`unicode-normalization =0.1.26`). Math alphanumerics, ligatures, superscripts, circled letters and full-width forms now match the same rules as their plain spellings. NFKC runs only on code points Unicode 14.0.0 assigns, so Python 3.11 and later and the crate agree. The ruleset digest changes.
