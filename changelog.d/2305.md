- The S31 `access` check now probes only the hub's own listeners, found by the
  hub processes' socket inodes, so the front's tailscaled peerapi in the shared
  namespace no longer fails it.
- A reachable host loopback listener at a hub port still fails `access`. An
  operator can exempt one with `--allow-loopback-listener PORT=REASON`, which
  applies only when the check can name the process holding the socket and that
  process is not the hub. The record keeps the reason, the holder's pid,
  executable and command name, and the listener's status line and headers.
