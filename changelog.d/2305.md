- The S31 `access` check now probes only the hub's own listeners, found by the
  hub processes' socket inodes, so the front's tailscaled peerapi in the shared
  namespace no longer fails it. A listener on a host loopback port is reported
  as INFO only when it proves by protocol that it is not the hub. A hub-like
  answer, a 401 or 403, or no answer still fails the check.
