- The S31 `access` check now probes only the hub's own listeners, found by the
  hub processes' socket inodes, so the front's tailscaled peerapi in the shared
  namespace no longer fails it.
- A reachable host loopback listener at a hub port still fails `access`. An
  operator can exempt one with
  `--allow-loopback-listener PORT=EXE_REALPATH//REASON`, which applies only
  when every process holding the socket runs exactly that executable, is not
  the hub, and the hub's network container publishes no port. The record keeps
  the path, the reason, each holder's pid, executable and command name, and
  the listener's status line and headers.
