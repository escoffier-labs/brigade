- When the Claude work-loop hook denies a raw verifier and the working tree changed the exact `subject_path` of a tracked verify manifest, the deny message now also names `brigade work verify run --target <repo> --manifest <manifest file> --capture auto`, in both the supported and the unsupported-structure deny. The manifest is named by its file path so an ambiguous id cannot break the command. A deleted subject is not named, since it cannot be scored. The agent's own replacement command is kept, and the manifest decides what gets scored (#2589).
- The Stop hook now blocks closeout when a tracked manifest's subject file was written by this session's own Edit, Write or NotebookEdit and no completed receipt carrying that manifest id started after the write. A manifest run that failed does not satisfy the gate. A subject that was only dirty, another session's write, or a shared tree the generic gate treats as foreign is not gated. Any git or manifest error leaves the Stop behavior unchanged (#2589).
- `brigade outcome rank` text output now shows `trials=<n>` from the scorecard's effectiveness dimension, so scoreable trials are visible without `--json` (#2589).
