- `brigade outcome reconcile` and the ratchet report now list pending rollback commands only for skills demoted within `pending_physical_window_days` (default 14, compared by exact time) or in the current run. A core skill demoted months ago no longer shows as an action to take. Install commands for a promoted skill come from current drift and are always listed. Older rollbacks are counted as `stale_physical_actions`, listed under `stale_physical` in the report and under a `stale:` heading in `brigade outcome ratchet`, and the brief line shows `stale=<n>` when nonzero. Every listed command carries the age of its status (`demoted 3 days ago`, plus `status_changed_at` in JSON), and a bump of a promoted skill now shows its pending install commands like an install does.
