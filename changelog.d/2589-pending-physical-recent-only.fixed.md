- `brigade outcome reconcile` and the ratchet report now list pending install or rollback commands only for skills whose status changed within `pending_physical_window_days` (default 14) or in the current run. A core skill demoted months ago no longer shows as an action to take. Older ones are counted as `stale_physical_actions` in the report, the brief line shows `stale=<n>` when nonzero, and every listed command carries the age of its status (`demoted 3 days ago`, plus `status_changed_at` in JSON).
