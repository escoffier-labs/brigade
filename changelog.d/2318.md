- Hub memory can use its own hub. Add `hub_url` and `node_token_file` to the workspace `[hub]` table, or set `BRIGADE_MEMORY_HUB_URL` and `BRIGADE_MEMORY_HUB_TOKEN_FILE`, and memory commands use that hub and token while `brigade fleet` keeps using `[fleet]`.
- `brigade memory hub status` reports which hub memory uses and where it came from (`env`, `[hub]` or `fleet`), and never shows the token.
