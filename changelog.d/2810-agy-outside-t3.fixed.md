- Read-only Antigravity seats now start as `agy --sandbox --mode plan --print`, so a researcher or reviewer seat can no longer write files through agy's edit tools (`--sandbox` restricts the terminal only). `brigade run` reads the resolved seat's `agy --help` and adds `--mode plan` only when the build lists it, so older agy builds keep the previous argv. Write seats are unchanged.
- Antigravity skills, commands and superpowers are now projected under `.agents/` (`.agents/skills/<id>`, `.agents/commands/`, `.agents/superpowers/`), the workspace root agy discovers, instead of `.antigravity/`. `brigade init` and `brigade reconfigure` remove the Brigade-owned copies at the old paths: managed tool projections whose body still matches the recorded fingerprint, and `SKILL.md` files that still match a text Brigade wrote or shipped. Edited or user-authored files, symlinks, Windows junctions and anything below them, and `.antigravity/memory-handoffs` are left alone, and `--no-wire` removes nothing. The managed gitignore block now ignores `.agents/commands/` and `.agents/superpowers/`. It leaves `.agents/skills/` tracked, because other harnesses read that directory and teams commit skills to it.
- A bare `gemini-<version>-<family>` model pin on an Antigravity seat, such as `gemini-4-hydrogen` or `gemini-4-neon`, now gets the default `-low` effort suffix, because agy lists Gemini models only as effort-suffixed slugs. Ids that already end in `-low`, `-medium`, `-high`, `-xhigh` or `-max`, and non-Gemini ids, are unchanged.
