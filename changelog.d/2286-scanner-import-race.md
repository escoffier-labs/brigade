- Scanner runs wait for every descendant that has released the capture pipes, including one that moved to its own process group, before reading `.brigade/scanner-imports.jsonl`, so a descendant still writing that file can no longer make a completed run ingest a partial file or report a misleading `import file not found`. A descendant that outlives the bounded drain is killed and fails the run with `scanner descendants still running after child exit`, with its import left unread, and the scanner's pid and process group id stay reserved for the whole drain so a recycled id is never probed or signalled.
