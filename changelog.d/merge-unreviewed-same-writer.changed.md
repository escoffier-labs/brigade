- A single exact-duplicate merge of two `agent-unreviewed` cards now passes the hub's `card_trust` gate when one credential wrote both cards and is the one applying, so it applies automatically on a real memory scope with no reviewer. Trust is unchanged and a rollback restores both cards. A flagged card, mixed trust, a pair written by different credentials or applied by another one, several pairs, a keeper retiring more than one card, a pair beside other ops, and `append_evidence` or `anchor_blocks` on `agent-unreviewed` cards stay held. Proposals over eight cards are refused at submit. Lineage review now reads every card of a merge at any trust, so an unreviewed pair with existing lineage, an escaped lineage value, or a live card naming the keeper waits for a reviewer.
