- `brigade fleet place --repo <key> [--threshold 0.70] [--json]` asks the Hub which machine should run a new child agent for a repository. It is advisory and strictly read-only: one read snapshot with writes refused, no decision stored, no reservation, no quota row created (#2166).
- Placement reuses the routing candidate evaluator, keeps only machines where the repository is a bound, fresh T3 project, and sheds any machine whose effective load (node-reported CPU or Hub-counted live sessions over concurrency, whichever is higher) is at or over the threshold. A missing, stale or null load excludes the machine (#2166).
- The answer names only the selected machine's T3 environment id and project id, stays local when the caller's own machine is under the threshold, honors a repository's `eligible_machines` policy, and expires after two minutes or sooner when the telemetry or inventory behind it does (#2166).
