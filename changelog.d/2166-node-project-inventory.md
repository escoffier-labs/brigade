- The T3 observer now reports each node's T3 projects that carry a canonical repository key (project id and `host.tld/segment/segment` key only, no paths, titles or URLs) to the Fleet Hub, which stores the latest set per node for read-only placement queries. Invalid rows are dropped and counted as `inventory_dropped`, and a stalled T3 descriptor cannot cost session publishing (#2166).
- Machines in the fleet policy can bind a `t3_environment_id`, unique across machines. The Hub rejects an inventory report whose environment id differs from the binding and clears that node's stored rows, and placement reads treat unbound or mismatched rows as unbound (#2166).
