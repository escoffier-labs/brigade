- A handoff aimed at a known instruction file (`USER.md`, `TOOLS.md`) now lands in a private overflow card under `memory/cards/instructions/` when the append would pass the file's act-at threshold or the file is reached through a symlink, instead of being held for a person. Each append is a journaled decision that `brigade memory care undo` reverses exactly.
- Review drafts held for a full instruction file (`bootstrap-budget-exceeded`) drain into the same overflow card on the next drain, and `handoff lint` and `handoff draft` no longer refuse those appends.
- Ingest and retry write to an overflow card only when this feature created it (private, `archive: never`, the `moved-instructions` tag, one frontmatter block). A planted or edited card is left untouched and the handoff is kept for a person as `overflow-card-untrusted`. A block that cannot fit an empty card is kept as `overflow-block-too-large`. Replay protection now covers every numbered card, including those after a gap, and the direct append path.
- Overflow appends are checked on the opened destination under the document lock, including recovery of a decision that was committed earlier: a card replaced after the commit receives nothing, and a direct append to an instruction file that no longer fits goes to its card in the same run. A file that was already hard linked still takes direct appends. `overflow-card-untrusted` is now a retry code that the drain re-evaluates every run, and ingest and the drain record each blocked card and the drafts waiting on it in `.brigade/memory-care/inbox/blocked-cards.json`.
