- Hub memory scan bundle `brigade-memory-scan.v6` adds a `private` class for network addresses, ports, local host names, root, home and Windows paths, email addresses, phone numbers, U+034F and U+200C. Private cards are stored, imported, searchable and loaded into local prompts, and every egress path refuses them with `memory_content_private`. The publication guard keeps its severities.
- Memory schema version 2 lets scan state `private` be stored. Existing memory files migrate on open with every row kept.
- U+FE0F after an emoji base or in a keycap no longer blocks, and `classic-injection` matches "exfiltrate" only as an order.
- `memory hub mirror` exports cards whose scan is private.
