- `brigade care install` no longer deletes the memory-care runbook directory when a shipped template is missing, and `brigade memory care init --with-runbooks` adds only missing runbooks and keeps existing ones unless `--force` is given, which replaces shipped files that differ from the templates after copying each to a `.bak-<UTC timestamp>` file. Operator-written runbooks are never overwritten or deleted, and `--dry-run` writes no runbooks at all.
