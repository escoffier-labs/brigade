- Add `brigade skills fleet drift [--refresh] [--report]`, a drift check for installed skill copies that needs no manual `skills fleet status` run. A copy byte-identical to a text a past release shipped, or a receipt-known bundled copy that was never edited, is refreshed. Any other drifted or locally edited copy is only flagged and is never written. Links, paths outside the workspace and copies it cannot compare are skipped. It reuses `skills fleet status` and the shipped-release history from the pristine refresh, so there is no second comparator.
- Run it weekly as a new `skill-drift` step at the end of the `weekly-outcome-ratchet` runbook. `brigade care install` refreshes an untouched copy of the earlier runbook, and a customized one is kept and reported as drifted.
- Write the result into `ratchet-report.json` under `skill_drift` with the current, refreshed and flagged counts and each flagged skill with its harness and path. `brigade work brief` prints it as a `skill_drift:` line next to `outcome_ratchet:`, the dashboard outcomes panel shows it, and `brigade outcome ratchet` prints it. A later `reconcile --report` keeps the last drift block. Refs #2590.
