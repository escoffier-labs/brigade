- Resume `brigade run cloud land` when the private runtime workspace under `XDG_RUNTIME_DIR` is gone, as happens after a logout or reboot: a `branch-pushed` landing allocates a fresh workspace, confirms the remote landing branch still points at the recorded commit, and creates the PR through the existing recovery path.
- Refuse the resumed landing with `landing-ref-missing` when the remote branch is gone and `landing-ref-mismatch` when it moved, so a cleared workspace never republishes different content. An existing workspace that fails the safety check is still refused with `unsafe-git-config`.
- Never rebuild or re-push a `branch-pushed` landing. A missing remote branch names the restore-or-adopt recovery, a fetched commit is verified in `FETCH_HEAD` before the local branch ref is created, and a failed resume removes its fresh workspace instead of recording it.
