- Add the outcome ledger code and a required `ledger-recompute` check inside `ci-gate`. The check rebuilds `outcome-ledger/skills.json` from trusted main, the git history of main and the Actions API, and rejects a ledger that differs, that omits a verdict the evidence holds now, or that touches anything but the ledger and a restored skill bundle. Trials are append only evidence carried forward from the previous ledger, so expired Actions runs cannot hide a failure. Expected verdicts come from git, so a deleted or cancelled `outcome-attest` run never helps a text: a missing or cancelled verdict counts as hurt with a recorded reason, and only a `success` conclusion helps. A malformed or truncated API answer fails closed, and a push to main is verified against the ledger it replaced, a first ledger included once the script is on main. The bundled `note` skill is the first manifest. The first ledger and the scheduled writer come in follow-up changes, so nothing is promoted or rolled back yet.
