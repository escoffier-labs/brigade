- Add the outcome ledger, `outcome-ledger/skills.json`, and a required `ledger-recompute` check inside `ci-gate`. The check rebuilds the ledger from trusted main, the git history of main and the Actions API, and rejects a ledger that differs, that omits a verdict the API holds now, or that touches anything but the ledger and a restored skill bundle. Trials are append only evidence carried forward from the previous ledger, so expired Actions runs cannot hide a failure. A failed or timed out `outcome-attest` job is a hurt trial, a malformed or truncated API answer fails closed, and a push to main is verified against the ledger it replaced. The bundled `note` skill is the first subject. Nothing writes the ledger automatically yet.
- Let `ci.yml` run on `workflow_dispatch`. A dispatched run takes full CI, and the lint allowlist base and the changelog guard use the merge base with main.
