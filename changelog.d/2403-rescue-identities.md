- Hold a worktree's Git admin directory open from the moment rescue verifies it, and compare the held descriptor's identity with the directory the worktree marker names, so a rename that swaps a replacement into that path can no longer redirect the Git listing rescue uses to decide whether a worktree is safe to delete.
- Remove a rescued worktree only while it is still the tree rescue verified. Removal now renames the tree to a private name through its held parent directory descriptor, checks the renamed entry's identity, and deletes only a match. A swap in that window keeps the worktree, restores the swapped-in directory untouched and reports `worktree-moved`, instead of deleting the decoy and leaving the rescued tree behind. Windows keeps the previous path-based removal.
