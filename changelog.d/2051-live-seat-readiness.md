- `brigade roster ready` runs prompt-free model inventory when model smoke is disabled, so direct Cursor, Grok, Ollama, and Antigravity seats can pass model reachability without an inference request. Ollama resolves its model from the `ollama:` cli suffix, each listing is bounded by the per-check health budget, and a seat `command` override is honored.
- Passive health checks map to passed with reason `not-applicable` only on explicit evidence: `version-gates` needs the dedicated `no-reviewed-gate` cause and is never mapped for ACPX or Antigravity, and `isolation-compatibility` needs `read_only=False` on the request. A generic `probe-incomplete` cause and the roster sandbox value no longer decide either mapping.
- Worktree isolation reports a fresh operation-scoped `isolation` observation with a `git-eligible` detail only when the Brigade route runs in a Git checkout with a committed HEAD; an unborn HEAD and a non-Git directory stay blocked. Eligibility does not prove disk space or worktree permissions.
- Plain-text `brigade roster ready` output now includes the operation scope and observation time.
