- `brigade run cloud land` now lints the generated PR body with an explicit Vale config that is either the repository's `.vale.ini` and styles read from the fetched default branch (never from the proposal) or a synthesized minimal one. Config and style files are copied byte for byte into a private directory, and a retry reuses the recorded base without fetching again. Unsafe `StylesPath` or `Transform` values, include or import keys, duplicate keys, inline comments, symlinks, gitlinks and oversized style files are refused as `unsafe-vale-config`. The operator's global Vale config still merges.
