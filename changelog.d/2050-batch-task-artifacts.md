- Retain each `isolation: worktree` batch task's result as an exact candidate commit plus a bounded patch: collection commits an uncommitted worker's leftovers with a fixed `Brigade <brigade@localhost>` identity and no hooks, records the worker's own commit when it made one, and reports `retained`, `no-changes`, `base-diverged`, or `collection-failed` separately from whether the worker succeeded.
- Write `batch-artifact-<sha256 of task id>.json` beside the run receipts with the base, branch, candidate, patch reference, digest and size, changed-path count, and ignored-file count. Journal `task.observed` uses `artifact_kind="commit"` and the sidecar digest when a candidate exists, `brigade.run_batch_result.v1` task entries gain an `artifact` member, and `brigade runs tasks show` reports the artifact sidecar reference and digest.
- Keep candidate patches local: they can carry untracked file contents, so `batch-artifact-*` files are excluded from every `brigade runs export` and archive surface. Ignored files are counted and never committed or patched, and collection never deletes, resets, cleans, or checks out anything.
