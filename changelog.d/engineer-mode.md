- The default work mode is now called engineer mode: `brigade work mode set engineer|yolo`, and `brigade init --engineer` switches a yolo install back (it cannot be combined with `--yolo`). Engineer mode behaves exactly as the old `enforced` mode did, with verification on. `enforced` is still read from existing configs and accepted by `brigade work mode set`, so no config needs editing. Hook wiring states such as the `enforced-idle` adoption state keep their names.
