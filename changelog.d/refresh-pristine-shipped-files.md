- After an upgrade, an installed `SKILL.md` (`brigade-work`, `ultra-work-scout`, `note`) or care runbook that is identical to a text a past Brigade release shipped for that file is replaced with the current bundled text, because it has no local edits. Init prints `refreshed (pristine): <path>`, records it in `wired.json`, leaves no backup, and marks the skills inbox proposal it had filed for that file as superseded. Any other differing copy is still never overwritten: a `SKILL.md` keeps today's `kept (edited)` and proposal, and a runbook is reported once as `kept (drifted)`. The past releases are recorded in `shipped-file-history.json`, generated by `scripts/shipped_file_history.py` and checked by `scripts/verify`.
