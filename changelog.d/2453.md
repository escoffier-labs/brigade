- Files evidence crawls now commit progress per file, skip unchanged content, and return success with a persisted resume cursor after a bounded run. Symlinks and private directories are excluded and files have an 8 MiB cap.
- Successful files crawls update scan manifests alongside the profile-specific cache. Exporter start errors fail the run without advancing its checkpoint. Unreadable ancestors cannot move a resume cursor backward.
- A failed export outside a budget stop checkpoints past the file and leaves it uncached. It is retried on the next sweep, rather than the next run. Unknown flags are rejected, and `--limit` now caps exporter invocations.
