- `brigade ingest` records an unreadable or unarchivable handoff as a failure, skips it and ingests the rest of the batch. The report adds a `Failed` count, a `PARTIAL` line and `Status partial`, and `brigade repos ingest` carries the failed count and status. `PARTIAL` joins the default ingestor warning patterns.
- `brigade ingest` also reads the handoff inboxes of linked git worktrees of each watched root, found through `git worktree list` with a 256-worktree cap. A handoff whose content was already handled in the same run is archived as a duplicate, so one handoff copied into several worktrees ingests once.
- Removing a worktree through Brigade (run cleanup, `brigade runs prune-worktrees`, model trials) first moves its pending handoffs into the main checkout's inbox, deduplicated by sha256. If a handoff cannot be delivered, the worktree is kept and a warning names it.
- In a linked worktree, the Stop hook now asks for the handoff in the main checkout's `.claude/memory-handoffs/`, which survives the worktree's deletion.
