- Publish the Python package as `brigadestack`. `pipx install brigadestack` and `uvx brigadestack` install the same `brigade` CLI, Python imports, and storage formats as before. `brigade-cli` stays on PyPI under the old name (#2816).
- `brigade update` upgrades a pipx app under the name it was installed with (`brigade-cli` or `brigadestack`) and resolves daily beta wheels from the `brigadestack` project, which is the only name that publishes them. A beta update of a `brigade-cli` app installs `brigadestack`, removes the old app, installs `brigadestack` again to restore launchers older pipx removes by name, then runs setup and records the update (on Windows it prints the two commands to run after it exits instead); if the removal fails, the update still succeeds and prints the `pipx uninstall brigade-cli` command (#2816).
- Count `brigadestack` and `brigade-cli` PyPI downloads together in the downloads badge, with a per-package breakdown in the metric JSON (#2816).
- The MCP Registry manifests launch `brigadestack`, the version check sends a `brigadestack/<version>` User-Agent, and install hints, the Dockerfile and the install docs name `brigadestack` (#2816).
