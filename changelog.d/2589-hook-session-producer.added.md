- A hook-enabled Claude session can now be the producer of a manifest verify trial when no `brigade work start` session is active. The hook records the target's start-of-session dirty files (`start.git.dirty_files`) once when it creates a session's state, bounded and failing open. `brigade work verify run --manifest` then names the single resolved Claude session `claude-hook:<fingerprint>` and runs every existing ownership check against that snapshot. An active work session still wins, and an ambiguous or worker-inherited identity picks no session (#2589).
- A verify typed in a Claude session now resolves its session once, through the hook value or `CLAUDE_CODE_SESSION_ID`, and stamps it on the receipt's `harness_session` and the verifier id alike. The Stop gate counts that receipt as the session's own, and a session is never independent of its own hook producer id (#2589).
