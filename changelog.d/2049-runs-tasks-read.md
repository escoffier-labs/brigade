- `brigade runs tasks list <run> [--json]` and `brigade runs tasks show <run> <task_id> [--json]` now expose durable per-task status, attempt, terminality, acknowledgement, containment, result id, artifact classification and digest, plus the batch result receipt path and digest. An unknown task exits 2 with `unknown-task`; a missing journal exits 2 with `no-task-journal`.
- `brigade runs tasks wait <run> [<task_id>...] [--timeout SECONDS] [--json]` waits for named tasks (default all) at a bounded poll interval. It exits 0 when every task is terminal and 3 on timeout with the non-terminal ids listed. A timeout records nothing and never cancels or changes execution. JSON output uses `brigade.runs_tasks.v1`.
