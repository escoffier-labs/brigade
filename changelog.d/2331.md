- `brigade memory hub import` takes folders as well as files and plans before it sends. `--dry-run` needs only read on the scope, lists exactly what the real run appends and writes nothing. It refuses when the hub's scan ruleset differs from this client's.
- Import keeps a frontmatter card id the hub accepts and otherwise derives a stable id from the note's path. It skips dot folders, the hub mirror's folder, symlinks and `--exclude` globs, and skips `visibility: private` notes with the push rules.
- Import deduplicates by the hub's content hash and reports each note as `import`, `unchanged`, `duplicate`, `changed`, `private`, `visibility-unrecognized`, `blocked`, `flagged`, `collision` or `error`, with rule ids only. A second run appends nothing, and `--update` overwrites a changed card from its current revision.
