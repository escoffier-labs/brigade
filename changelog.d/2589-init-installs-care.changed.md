- `brigade init` now turns on extras and installs the default care schedule, the same as running `brigade extras on` and `brigade care install --target <target>` after init, so the weekly outcome ratchet runs with no further step. Pass `--no-care` to skip both. A host with no scheduler still exits 0, prints one warning that names the care install command, and a repeat init leaves an installed schedule alone. `--dry-run` lists both steps without running them. New `--json` prints one result object with the status of the extras and care steps (#2589).
